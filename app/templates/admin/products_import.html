What your sheet needs

A simple sheet works. The first row should be headings like:

Name · Category · Price · Stock · SKU · UPC · Cost

  • New products need a Name and Price.
  • Products already on the site are matched by name and updated.
  • Blank cells leave existing values as they are.
  • New category names are created for you.
  • For colors, use the full template (color_name column).
